Detailed Description

La table d'un lieu : type de tuile → pièces, pour le sol et pour le relief.

Logique pure (aucun Qt, aucun GPU, EX-NFR-010). Aucune lecture ne lève (EX-NFR-040) : un fichier absent donne une table vide, et une case sans pièce ne dessine rien plutôt que de tomber sur un damier sur sept mille cases.

La pièce de sol d'une case.

La variante est choisie par la case : (colonne × 7 + ligne × 13) % nombre de variantes. Un tirage aléatoire ferait scintiller le sol d'une image à l'autre ; un compteur ferait dépendre le sol de l'ordre de parcours.

Returns
Le nom de la pièce (sand-2), vide si le type n'a aucune pièce dans ce lieu.

Le type que la table donne à piece : la réciproque de floorPiece (floor) ou de reliefPiece (LOT-EDITOR-03).

Une pièce posée à la main garde ainsi le type dont la table la tirerait, et le type reste le sens de règle de la case (décision D3).

Returns
Le premier type, dans l'ordre de l'énumération, dont la table cite piece (ou la pièce dont piece est un ancien nom) ; std::nullopt si aucun ne la cite.
