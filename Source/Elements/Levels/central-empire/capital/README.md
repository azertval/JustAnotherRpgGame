# Les cartes de la Capitale

Les cartes **jouables** suivent le même découpage que les assets :
`Levels/<région>/<ville>/<zone>.json`, et la sous-zone sous son dossier de zone.

La table rase du `LOT-102` a emporté celles de l'ancien style. Les nouvelles se dessinent à
l'éditeur : `arenarea.json` (LOT-109), `martpart.json` (LOT-111), `arenarea/arena-of-fate.json`
(LOT-107).
