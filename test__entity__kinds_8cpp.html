ToutFamilleLueParLeJeuEstDansLaTable  )

Contrat d'extension (§5, règle 2 de la feuille de route de l'éditeur) : toute famille d'entité que le jeu lit est dans core::knownEntityKinds, et reçoit donc inspecteur, forme et contrôle sans code d'éditeur.

Cas de test : Aucune famille lue par le jeu n'echappe a l'editeur.
Categorie : Unitaire · Familles d'entites
Criticite : Bloquant
Etapes :
1. Relever dans les sources du jeu (Core, HMI, App) chaque constante *_ENTITY_TYPE.
2. Y ajouter les familles interactives (core::knownInteractableKinds) et chaque type des cartes livrees.
3. Chercher chacune dans la table.
Resultat attendu : Toutes y sont ; le releve trouve au moins les onze familles d'aujourd'hui.
