# La compagnie : équipes, rangs de Guilde, quartier général

Ce que la version `0.2.0` doit couvrir. Le mot « compagnie » est celui du projet ; le terme de règle des livres est **Adventure Team**.

> Pages données en pages **de livre**. Dans le *Player's Guide* et le *Sourcebook*, la page PDF *n* porte les pages de livre 2*n*−2 et 2*n*−1 ; dans le *Manuel des Joueurs*, page PDF = page de livre. Ce qui n'est pas lu mot pour mot dans un livre est marqué **déduit**.


## Où c'est

| Sujet | Livre | Pages |
|---|---|---|
| **Teams** (règle optionnelle : style, Career Points, niveaux d'équipe, QG) | PG chap. 5 | **300-303** |
| **Structures** du QG (12, chacune avec son employé) | PG | **304-315** |
| Legendary Rewards, Team Feat List, Team Heroic Staff | PG | **316-317** |
| Heroic Mark and Arena Combats, Betting in the Arena | PG | 318-321 |
| **Adventurer's Guild** et rangs Iron → Diamond | SB, Republic of Freelands | **105-106** ; siège à Fisherman's Wharf, district 10 Uptown (p. 113) |

Le mot « company » ne désigne aucune règle dans les deux livres : le terme de règle est **Adventure Team**. Les rangs de guilde sont dans le Sourcebook, sans mécanique autre que les niveaux typiques.

## Mécanique en dix lignes

1. L'équipe remplit une **Team sheet** : nom, devise, membres, **style** parmi quatre — Explorers, Investigators, Operatives, Special Forces (PG p. 300).
2. Les hauts faits rapportent des **Career Points** attribués par le MJ (p. 301) : Common Task 1 · Well-done Task 2 · Hard Task 3-5 (ex. gagner un combat d'arène) · Important Job 6-8 · Heroic Feat 9-13 · Legendary Feat 14-18 · World Changing 19+.
3. **Niveau d'équipe 1 à 20** par seuils (p. 302) : 0, 10, 20, 30, 40, 50, 70, 90, 110, 130, 150, 170, 200, 230, 260, 290, 320, 350, 400, 450.
4. **Team Features** aux niveaux 1, 5, 13 selon le style (p. 303) : au N1, une maîtrise de compétence par membre (Explorers : Nature / Perception / Survival ; Investigators : Investigation / Perception / Insight ; Operatives : Stealth / Sleight of Hand / Deception ; Special Forces : Athletics / Acrobatics / Intimidation) ; N5 et N13 : Trailblazer / No Need For An Invitation, Investigative Eye (15 automatique en test de groupe) / Law's Arm, Silver Tongue / Information Hub, Inspiring Force / Heroic.
5. **Quartier général au niveau 2** : 1 point dans le **Main Hall** + 2 **Structure Points** ; ensuite 2 points à la plupart des niveaux ; les points posés ne se réallouent jamais (p. 301-302).
6. Poser un point sur une structure vide la construit (capacité de rang 1) ; en ajouter l'améliore ; **plafond par structure** selon le niveau d'équipe : 2 (N2-4), 3 (N5-8), 4 (N9-12), 5 (N13-16), 6 (N17-20).
7. **12 structures**, chacune avec un employé (Staff) doté d'un bloc de stats : Main Hall / Butler (304), Arcane Library / Arcane Scholar (305), Stable / Breeder (306), Workshop / Craftsman (307), Tavern / Tavern Keeper (308), Healing Hall / Doctor (309), Observatory / Wayfinder (310), Fortress / Head Guard (311), Farm / Farmer (312), Museum / Curator (313), Pier / Harbor Master (314), Garden / Herbalist (315).
8. **Legendary Rewards** aux niveaux 10, 12, 14, 16, 18, 20 (p. 302, 316) : Magic Item, Team Feat, Powerful Ally, Legendary Headquarter (+2 Structure Points), Portal, Heroic Staff Member, Monument.
9. **Team Feats** (p. 316-317), 12 : Coordinated Attack, Group Opportunity, Group Perception, Information Collectors, Magic Team, Phalanx Tactics, Programmed Tactics, Proper Start, Resource Management, Stealthy, Trained by Colleague, Unified Actions.
10. **Rangs de l'Adventurer's Guild** (SB p. 105-106) : Iron (niv. 1-2) · Copper (3-4) · Bronze (5-6) · Silver (7-10) · Gold (11-16) · Diamond (17+). La guilde enregistre les aventuriers, affiche les quêtes, et **interdit les tâches au-dessus du rang** — un verrou de contenu tout trouvé (**déduit**).

Articulation (**déduit**) : le rang de guilde suit le niveau des personnages, le niveau d'équipe suit les Career Points ; « gagner un combat d'arène » vaut 3-5 points, ce qui relie le Colisée déjà livré à la progression d'équipe.

Complément arène (PG p. 318-321) : **Heroic Mark**, 8 types (Brute, Bruiser, Commander, Controller, Healer, Shooter, Tactician, Tank) ; 2 Basic + 2 Special Heroic Actions par repos court, une action héroïque par tour, chacune une fois par rencontre ; Special communes : Heroic Denial, Heroic Shield, Heroic Survival ; n'agit que dans la zone du rituel. Le cadre « Heroic Mark » figure sur les quatre fiches préfabs, vide.
