# Référentiels

Ce que les livres donnent à faire, relevé une fois, page à l'appui. Les lots **citent** ces pages ;
ils ne recopient pas le livre.

Trois règles de lecture. Les pages sont des pages **de livre**, pas de PDF. Ce qui n'est pas lu mot
pour mot est marqué **déduit**. Et les livres sont une référence de **contenu** : aucune de leurs
images n'entre dans le jeu.
