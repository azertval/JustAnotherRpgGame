Create ONE finished game scene, 1536 x 1024, landscape: a small fragment of a
market street in the capital of a fantasy empire, seen in isometric view, with
the two characters of reference image 1 standing in it.

PIXEL SCALE (most important): 16-bit pixel art, 2 screen pixels per art pixel,
crisp square pixels, no anti-aliasing, no gradients, no blur. The ground AND the
characters share this same pixel size. Copy the characters of reference image 1
exactly: same size (about 90 screen pixels tall), same outline, same shading.
The scenery must be drawn with the SAME outline, shading and pixel density as
these two characters, so that they look native to the place.

GRID: reference image 1 shows the floor grid as thin outlines. Each floor tile is

floor tile, laid out on this grid, but DO NOT draw the grid lines themselves.

PLACE: cobblestone street, lantern-lit market stalls with striped awnings and

CAMERA AND LIGHT: fixed isometric camera, no perspective. One outline colour:
deep navy, never pure black, one pixel wide. Three to four tones per material.
Single light source top-left; warm lantern glow drawn as flat pixel tones, no
bloom. No ground shadow under the characters.

COMPOSITION: the scene fills the image edge to edge; the characters stand on
two different floor tiles near the centre, facing the viewer.

FORBIDDEN: any text, letters, numbers, labels, captions, user interface, panels,
borders, frames, colour swatches, logo, watermark, grid lines.
