# Annexes de la version 0.0.0

Ce qu'un lot a laissé à côté de sa fiche : un atelier (scripts, prompts, ancres), des captures, des
maquettes de référence, des retouches. Un dossier par lot, sous le nom du lot.

| Dossier | Lot | Ce qu'il contient |
|---|---|---|
| `LOT-09-colisee-premiere-carte/` | [LOT-09](../lots/LOT-09-colisee-premiere-carte.md) | `atelier/carte_colisee.py` : le script qui écrivait la carte du Colisée, avant que l'éditeur ne sache le faire. |
| `LOT-87-charte-v2/` | [LOT-87](../lots/LOT-87-charte-v2.md) | Le [cahier des assets](LOT-87-charte-v2/assets-brief.md) (engendré de `assets-brief.json`, contrôlé en CI), les dix maquettes de référence (`references/`), les captures 720p / 1080p des écrans (`captures/`), les planches reçues (`images-produites/`). |
| `LOT-91-atelier-pnj/` | [LOT-91](../lots/LOT-91-atelier-pnj.md) | Le [PoC](LOT-91-atelier-pnj/poc.md) et l'atelier des PNJ : ancres, prompts, scripts, cinq PNJ. |
| `LOT-92-atelier-textures/` | [LOT-92](../lots/LOT-92-atelier-textures.md) | L'atelier des textures : maquette, prompts, dispositions. |
| `LOT-93-atelier-monstres/` | [LOT-93](../lots/LOT-93-atelier-monstres.md) | L'atelier des monstres : lion, loup, soldat Ironhand. |
| `LOT-96-quartiers-capitale/` | [LOT-96](../lots/LOT-96-quartiers-capitale.md) | `atelier/carte_quartiers.py` : le script des cartes de quartier. |
| `LOT-EDITOR-06-fin-des-scripts/` | [LOT-EDITOR-06](../lots/LOT-EDITOR-06-fin-des-scripts.md) | `retouches/` : les trois fichiers de gestes rejoués par `LevelEditor --apply`. |

Les maquettes de référence et les captures du `LOT-87` illustrent aussi le guide et les
spécifications de l'interface : elles restent ici, et ces pages les citent.
