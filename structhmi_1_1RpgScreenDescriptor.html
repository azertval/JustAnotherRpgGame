Detailed Description

Comment un écran est rendu (LOT-38).

Le LOT-68 n'avait qu'une voie : une ossature en données, peinte par un rendu générique. C'était le bon outil pour huit écrans dont aucune maquette n'existe. Un écran qui a une maquette gravée — la fiche de personnage et ses cinq planches — mérite mieux qu'un résumé en deux colonnes : il reçoit sa planche, décrite en Qt Designer, et garde le même cadre, la même navigation et le même pied d'actions que les autres.

Le champ est ici, dans la table, et non deviné par le code qui construit les écrans : c'est la description de l'écran qui dit comment il se rend, exactement comme elle dit s'il suspend la simulation. Description complète d'un écran du RPG.
