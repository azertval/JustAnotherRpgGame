Compose la partie fixe de snapshot (tout sauf ses figurines) et l'indexe.

Les textures de textures doivent être celles du dessin : une pièce dont la texture n'est pas encore chargée se compose sur le damier, comme dans composeWorldScene.

◆ compose()

void hmi::StaticWorldScene::compose ( ComposedScene & out,
std::span< const WorldFigureSnapshot > figures,
const ScenePieceTextures & textures ) const

Compose une image dans out : la partie fixe sous le cadrage de out, et figures, dans l'ordre de dessin.

Le cadrage est celui de out (ComposedScene::setVisibleBounds) ; sans cadrage, toute la carte. out est remplacée si elle est vide, sinon la composition s'y ajoute et l'appelant la retrie.

Parameters
outLa scène de l'image.
figuresLes figurines de l'image, héros compris ; leur dossier se lit dans l'instantané passé à build.
texturesLes textures du dessin (celles des figurines comprises).
