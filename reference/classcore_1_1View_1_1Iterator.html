Detailed Description

template<typename... Components>
class core::View< Components >::Iterator

Itérateur avant sur les entités retenues par la vue.

Déréférencé, il fournit un std::tuple<Entity, Components&...> (handle puis références sur les composants), ce qui autorise la liaison structurée for (auto [entity, ...] : view).
