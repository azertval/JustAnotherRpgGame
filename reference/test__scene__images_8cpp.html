Detailed Description

Le cache d'images du canevas : partagé, borné, lu une fois (LOT-125).

Une pièce HD pèse seize fois une pièce de l'ancienne planche. Ces tests prouvent ce qui tient la mémoire de l'éditeur sous la borne de son README : une seule instance par dossier d'assets pour tous les onglets, un budget de pixels tenu par éviction, une image évincée qui se relit à l'identique, et un manifeste lu une fois pour toutes les pièces de son dossier. Les images sont celles de la maquette HD (Fixtures/HdMockup), à la définition du standard.

Le cache tient son budget : au-delà, la pièce la moins récemment peinte est évincée, et se relit à l'identique à la peinture suivante.

Cas de test : Le cache d'images tient son budget.
Categorie : Unitaire · Editeur · Canevas
Criticite : Bloquant
Etapes :
1. Creer un cache dont le budget tient la plus grosse piece de la maquette, pas toutes.

  1. Charger toutes les pieces, puis peindre (lire) chacune.
  2. Relire la premiere.
    Resultat attendu : Apres chaque lecture, les octets tenus restent sous le budget (la piece lue exceptee) ; la premiere piece, evincee, se relit pixel pour pixel.

Tous les onglets d'un même dossier d'assets partagent un seul cache.

Cas de test : Le cache d'images est partage entre onglets.
Categorie : Unitaire · Editeur · Canevas
Criticite : Majeur
Etapes :
1. Demander trois fois le cache partage du dossier de la maquette, comme trois onglets.

  1. Relacher les onglets un a un.
    Resultat attendu : Les trois demandes rendent la meme instance ; elle vit tant qu'un onglet la tient.

Les niveaux réduits d'une pièce peinte se calculent à la demande ; une image engendrée n'en a pas.

Cas de test : Une piece peinte a ses niveaux reduits.
Categorie : Unitaire · Editeur · Canevas
Criticite : Majeur
Etapes :
1. Charger une piece de la maquette et lire son niveau 1 et son dernier niveau.

  1. Lire un marqueur d'entite.
    Resultat attendu : Le niveau 1 fait la moitie de la piece, le dernier un pixel de cote au plus ; la piece est lissee, le marqueur ne l'est pas et n'a qu'un niveau.
