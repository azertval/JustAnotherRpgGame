Cas de test : Un prefabrique garde ses etages.
Categorie : Unitaire · Editeur · Etages
Criticite : Bloquant
Etapes :
1. Poser un toit a l'etage 1, decouper le batiment, l'ecrire puis le relire.

  1. Le poser sur un autre batiment dont les couches portent d'autres noms.
  2. Relire un prefabrique dont la couche de sol pretend etre a l'etage 1.
    Resultat attendu : La couche relue est a l'etage 1 ; le toit se pose sur la couche d'etage, pas au rez ; le prefabrique faux est refuse.
