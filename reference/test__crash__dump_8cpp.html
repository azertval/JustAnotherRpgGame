Detailed Description

Minidump sur plantage (HMI/Platform/CrashDump) : nom du fichier et écriture réelle.

Le filtre d'exception non attrapée ne se teste pas en processus : il termine le processus. Le test de fumée de la release le prouve de bout en bout (--crash-test). Ici, ce qui le compose : le nom du fichier, et l'écriture d'un dump lisible, avec et sans contexte d'exception.
