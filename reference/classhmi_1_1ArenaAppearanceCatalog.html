Detailed Description

Catalogue d'apparence du Colisée : figurines par côté, dalles de sol, chargé depuis Source/Elements/Assets/Coliseum/manifest.json (heroes, gladiators, heroFrames, enemyFrames, paleSlabs).

Logique pure (aucune dépendance Qt ni GPU, EX-NFR-010), testable sur des grilles connues sans construire de BattleGrid. Aucune lecture ne lève d'exception (EX-NFR-040).

Applique les remplacements déclarés par le manifeste des PNJ (Source/Elements/Assets/Npc/manifest.json, champ replaces : héros → slug).

◆ replaceHero()

bool hmi::ArenaAppearanceCatalog::replaceHero ( std::string_view hero,
std::string directory )

Fait lire les bandes d'un héros dans un autre dossier — la figurine de remplacement d'un PNJ de l'atelier (LOT-91) à la place d'un héros de la planche de production.

Le nom du héros ne change pas : le roster, la sélection par nom et la clé des clips restent ceux du manifeste du Colisée ; seul le dossier lu diffère.

Parameters
heroUn nom de heroes().
directoryDossier des bandes, relatif au dossier du Colisée (ex. ../Npc/anariel).
Returns
Faux, sans effet, si hero n'est pas dans le roster.

const std::string & hmi::ArenaAppearanceCatalog::scene ( ) const
inlinenodiscardnoexcept

Le lieu dont l'arène emprunte ses pièces de scène (champ scene du manifeste).

La composition lit les sols et l'enceinte dans ../Scene/<lieu>/, à côté du dossier du kit. Le kit dit donc lui-même de quelle planche il se sert : rien n'est écrit en dur dans le moteur (LOT-102).
