Les noms de progression font l'aller-retour, et un nom inconnu est refuse.

Cas de test : Les noms de progression de lanceur font l'aller-retour sans perte.
Categorie : Unitaire · Multiclassage
Criticite : Majeur
Etapes :
1. Convertir chaque progression en nom, puis le nom en progression.

  1. Analyser un nom inconnu.
    Resultat attendu : La progression d'origine est retrouvee ; le nom inconnu est refuse sans exception.
