Detailed Description

Tests de l'avertissement d'une rencontre mal posée (LOT-11, EX-CBT-001).

Le combat se joue sur la carte d'exploration : toute carte doit être un terrain tactique valide. Les cartes sont écrites ici, à la case près, pour qu'un seuil déplacé se voie au premier test qui le franchit.
