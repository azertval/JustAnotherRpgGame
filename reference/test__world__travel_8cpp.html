Detailed Description

Tests du graphe du monde JOUE (LOT-09) : franchir un portail, arriver a un point nomme, garder la carte quittee, et refuser au chargement ce qui ne mene nulle part.

TEST ( WorldTravelTest ,
CinqCartesSeParcourentDansLesDeuxSens  )

Cinq cartes se parcourent dans les deux sens par points d'arrivee nommes.

Cas de test : Un parcours de cinq cartes, aller et retour, par points d'arrivee nommes.
Categorie : Unitaire · Monde parcouru
Criticite : Critique
Etapes :
1. Entrer sur la premiere carte, puis franchir quatre portails a la file.

  1. Revenir par les portails de retour jusqu'a la premiere carte.
    Resultat attendu : Chaque traversee pose le personnage sur le point d'arrivee NOMME de la carte atteinte, jamais sur une coordonnee du portail de depart.

TEST ( WorldTravelTest ,
LesCartesDuPremierDossierPassentDevant  )

Le chargeur a plusieurs dossiers sert le premier qui porte la carte, et n'invente rien.

Cas de test : Les cartes du brouillon passent devant celles du jeu.
Categorie : Unitaire · Monde parcouru
Criticite : Critique
Etapes :
1. Poser deux dossiers, la meme carte dans les deux sous un nom different, et une seconde carte dans le dernier seulement.
Resultat attendu : La carte commune vient du PREMIER dossier ; celle qui n'est que dans le second en vient ; une carte absente des deux echoue.

Une arrivee inconnue refuse l'entree et nomme ce qui manque.

Cas de test : Entrer par un point d'arrivee absent est refuse, le nom cite.
Categorie : Unitaire · Monde parcouru
Criticite : Majeur
Etapes :
1. Entrer sur une carte par un point d'arrivee qu'elle n'offre pas.
Resultat attendu : UnknownArrival, le defaut cite le nom demande, et la carte courante ne change pas.

TEST ( WorldTravelTest ,
UnPointDArriveeEnDoubleEstReleveSurLaCarte  )

Un point d'arrivee en double est releve sur la carte.

Cas de test : Deux points d'arrivee du meme nom sont un defaut de la carte.
Categorie : Unitaire · Monde parcouru
Criticite : Majeur
Etapes :
1. Poser deux points d'arrivee « seuil » sur la meme carte.

  1. Valider la carte lue, puis le graphe.
    Resultat attendu : La carte signale le doublon, que le graphe ne peut pas voir : il deduplique les noms.

TEST ( WorldTravelTest ,
UnPortailADrapeauResteFermeSansLeDrapeau  )

Un portail a drapeau reste ferme tant que le drapeau n'est pas pose.

Cas de test : Un portail exigeant un drapeau ne s'ouvre qu'une fois le drapeau pose.
Categorie : Unitaire · Monde parcouru
Criticite : Critique
Etapes :
1. Franchir un portail qui exige un drapeau absent.

  1. Poser le drapeau, puis franchir le meme portail.
    Resultat attendu : Locked d'abord, Moved ensuite : le drapeau vit dans le monde, pas dans la carte.

Un portail orphelin est refuse au chargement, pas a la traversee.

Cas de test : Chaque defaut de portail devient un code exploitable au chargement.
Categorie : Unitaire · Monde parcouru
Criticite : Critique

    Resultat attendu : Un defaut par portail fautif, nomme et situe, releve AVANT que le joueur n'y marche.
