TEST_F ( FileLogSinkTest ,
CheminInvalideSinkFermeEtWriteSilencieux  )

Un chemin impossible à ouvrir (dossier parent qui ne peut pas être créé) laisse le sink fermé (isOpen() == false) sans lever d'exception ; write() devient alors un no-op silencieux — journaliser ne doit jamais faire échouer l'appelant.

Cas de test : FileLogSink : chemin invalide, sink fermé, write() silencieux.
Categorie : Unitaire · Diagnostics
Criticite : Mineur
Etapes :
1. Construire un FileLogSink dont un segment du chemin est en réalité un fichier existant (impossible à traverser comme dossier).
2. Appeler write().
Resultat attendu : isOpen() == false ; write() ne lève rien et ne crée aucun fichier.
