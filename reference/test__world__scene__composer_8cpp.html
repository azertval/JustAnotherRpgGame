Detailed Description

Tests de la composition d'un lieu parcouru (LOT-09) : le sol vient du type de tuile, le relief de la piece nommee a la case, et la figurine se pose au pied de sa case.

TEST ( MaquetteRenderTest ,
LaCouleurDuJetonSeDeduitDeLEntite  )

La couleur d'un jeton se déduit de ce que le format dit déjà, sans propriété nouvelle (décision D3) : le dialogue fait le jaune, la rencontre le rouge, le camp d'une entrée d'arène l'un ou l'autre.

Cas de test : La couleur d'un jeton se deduit de ce que le format dit deja.
Categorie : Unitaire · Jetons de maquette
Criticite : Critique
Etapes :
1. Poser un PNJ avec dialogue, un sans, un avec figurine, une rencontre, deux entrees d'arene, un point d'apparition, un portail et un coffre.
2. En tirer les marques.
Resultat attendu : Chaque jeton porte la nature attendue ; le PNJ qui a deja sa figurine n'a pas de jeton.

Cas de test : Une carte habillee garde ses jetons mais perd ses traces.

Criticite : Critique
