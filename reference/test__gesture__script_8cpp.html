Detailed Description

Tests de l'éditeur sans fenêtre (LOT-EDITOR-13) : un scénario --apply par outil, comparé à un fichier attendu, les gestes refusés, et l'acceptation du lot — une rue de la carte d'essai effacée puis retracée la rend, octet pour octet.

Les scénarios vivent dans Source/Test/Fixtures/Gestures/ : <outil>.json rejoué sur terrain.json doit rendre <outil>.attendu.json. Un changement voulu se régénère par l'éditeur lui-même, puis se relit en diff :

LevelEditor --data Source/Test/Fixtures/GameData --apply Source/Test/Fixtures/Gestures/paint.json
Source/Test/Fixtures/Gestures/terrain.json
--output Source/Test/Fixtures/Gestures/paint.attendu.json

Les outils qui ne touchent pas à la carte disent ce qu'ils ont fait : la mesure dans le compte rendu, les notes dans l'annexe.

Cas de test : La mesure et les notes rendent leur compte rendu et leur annexe.
Categorie : Unitaire · Editeur · Sans fenetre
Criticite : Majeur
Etapes :
1. Rejouer measure.json puis note.json.
Resultat attendu : La mesure écrit 7 × 4 · 6 cells = 30 ft ; l'annexe égale note.attendu.editor.json : une note gardée, une retirée.

TEST ( GestureScriptTest ,
UneRueRefaiteRendLaCarteALOctet  )

Acceptation du lot : la rue du nord de la carte d'essai, effacée puis retracée par --apply — pavés, seuils, façade, portes, fenêtres, lanternes — rend la carte.

Les gestes sont ceux de la main dans la fenêtre : une sélection gommée par couche, un rectangle de pavés, un trait par variante de pavé, une ligne de façade, un trait de fenêtres, de portes et de lanternes. Qu'ils rendent le fichier tel qu'il est sur disque montre que les outils posent la pièce, le type de sa case et la collision comme la carte les porte. Cas de test : Une rue refaite par –apply rend la carte, octet pour octet.
Categorie : Unitaire · Editeur · Sans fenetre
Criticite : Critique
Etapes :
1. Rejouer Fixtures/Gestures/rue.json sur bourg/place.
Resultat attendu : Dix gestes, dix pas d'annulation ; le texte égale place.json octet pour octet.

--apply refusé n'écrit rien ; accepté, il écrit la carte et son annexe.

Cas de test : Un geste refusé ne touche pas au fichier.
Categorie : Unitaire · Editeur · Sans fenetre
Criticite : Critique
Etapes :
1. LevelEditor --apply d'un fichier dont le deuxième geste est refusé, avec --output.
2. Le même, avec des notes seulement.
Resultat attendu : Code 1, « nothing written », aucun fichier écrit ; puis code 0, la carte et son annexe écrites.

Criticite : Majeur

Resultat attendu : Chaque fois, une erreur qui nomme le geste et sa raison.
