Detailed Description

Tests unitaires de core::DeterministicRandom, splitMix64 et deriveSeed (EX-NFR-002).

Ce fichier fige des vecteurs de référence : les valeurs attendues y sont écrites en dur, calculées indépendamment de l'implémentation. C'est le seul moyen de détecter qu'une refonte a silencieusement changé la suite produite — auquel cas toutes les séquences de particules déjà observées changeraient sans qu'aucun autre test ne s'en aperçoive : elles resteraient reproductibles, simplement plus les mêmes.
