Detailed Description

Tests du combat sur la carte (LOT-118) : une rencontre engagée pendant l'exploration se monte sur la zone de combat de la carte, se joue par les gestes du Colisée, se montre par les figurines de la carte gelée, et rend l'exploration.

La vue-modèle lit ses règles à côté de l'exécutable, comme le jeu ; la carte et le contenu — la rencontre, le rat d'essai, le maître d'arène d'essai — viennent de la racine d'essai (Source/Test/Fixtures/GameData).

TEST ( EncounterModelTest ,
DuDeclenchementAuRetourALExploration  )

Une rencontre engagée depuis la carte se monte sur sa zone de combat, se joue, se voit et rend l'exploration.

Tant qu'elle dure, c'est elle qui tient la carte gelée, d'où qu'elle ait été engagée (EX-IHM-091). Cas de test : Du declenchement sur la carte au retour a l'exploration, sans fenetre.
Categorie : Unitaire · Combat sur la carte
Criticite : Bloquant
Etapes :
1. Ouvrir le donjon d'essai, le heros devant le maitre d'arene, dans la zone « salle ».
2. Engager « rats-du-donjon » a la graine 2026.
3. Jouer : attaquer le rat le plus proche, finir le tour, jusqu'a l'issue ou dix rounds.
4. Quitter.
Resultat attendu : Le combat est monte : carte gelee, quatre combattants, zone d'origine (10, 10), le heros en (14, 9) de la grille ; les figurines publiees sur la carte ont montre une attaque et une mort (un rat a 1 PV tombe sans passer par le touche) ; a la sortie, la carte degele, ses figurines reprennent, le heros est la ou le combat l'a laisse, et finished porte l'issue.

LeCombatLaisseAuxFichesCeQuIlEnReste  )

Ce que le combat laisse aux fiches (LOT-139) : les points de vie qui restent sont relus au combat suivant et montrés par l'écran de groupe ; un membre mort quitte le groupe, et s'il menait, le suivant mène.

Cas de test : Le registre du groupe : points de vie relus, mort qui ne suit plus.
Categorie : Unitaire · Combat sur la carte
Criticite : Critique
Etapes :
1. Noter au registre 5 PV pour le Brawler ; engager les rats.
2. Fuir ; lire le registre.
3. Enterrer le Brawler, puis tenter d'enterrer tout le monde.
Resultat attendu : Le Brawler entre en combat a 5 / 15, l'ecran de groupe le dit ; apres la fuite, chaque membre a un enregistrement, au moins 1 PV ; enterre, le Brawler quitte le groupe, le Priest mene, deux suiveurs ; le dernier ne s'enterre pas.

Le niveau donné survit au combat, et le repos rend la fiche pleine à ce niveau (LOT-142) : la série de l'arène donne un niveau et un repos entre deux combats.

Cas de test : Un combat garde le niveau donne ; le repos rend les points de vie.
Categorie : Unitaire · Combat sur la carte
Criticite : Critique

2. Lire le registre.

  1. Donner un repos au groupe ; engager les rats.
    Resultat attendu : Apres la fuite, chaque membre garde le niveau 2 au registre ; apres le repos, il n'a plus de points de vie retenus, et le Brawler entre en combat plein, au maximum du niveau 2.

TEST ( EncounterModelTest ,
LeRejeuAGraineFixeeDonneLeMemeCombat  )

Le rejeu à graine fixée donne le même combat (LOT-139) : deux rencontres montées à la même graine, jouées par les mêmes gestes, écrivent le même journal — et chaque membre du groupe y est joué par le joueur à son tour (EX-CBT-061).

Cas de test : Deux combats de groupe a la meme graine sont identiques.
Categorie : Unitaire · Combat sur la carte
Criticite : Critique
Etapes :
1. Engager les rats a la graine 41, jouer trois rounds (attaquer, finir le tour), relever le journal, fuir.
2. Reposer le groupe, recommencer a la meme graine.
Resultat attendu : Les deux journaux sont identiques, et ont vu plus d'un membre du groupe jouer.

LInterfaceDeGroupeLitLaVueModele  )

L'interface de combat de groupe (LOT-140, EX-IHM-108) lit ce que la vue-modèle publie : le round, les jetons de l'ordre d'initiative, le panneau du combattant actif, le détail des actions et la prévisualisation de l'action choisie sur la case du curseur.

Cas de test : Round, jetons, panneau de l'actif, actions detaillees, previsualisation.
Categorie : Unitaire · Combat sur la carte
Criticite : Critique
Etapes :
1. Engager les rats a la graine 2026, jusqu'au tour du joueur.
2. Lire round, turnOrder, activeProfile, turnActions.
3. Viser le rat le plus proche avec la premiere attaque ; puis ramener le curseur sur soi ; puis viser une case libre atteignable.
Resultat attendu : Round 1 ; chaque ligne de l'ordre a ses initiales, les membres du groupe leur jeton s'il est installe ; le panneau porte la classe, le niveau 1, une action et un deplacement a depenser, les capacites de la fiche ; la premiere action ecrit son jet et ses des ; la previsualisation est une attaque titree « arme → cible » avec la ligne « Toucher », puis refuse la case d'un allie, puis decrit un deplacement.
