TEST ( QuestAdvanceTest ,
LesUsagesDeDrapeauxSontConfrontesAuxDeclarations  )

Un dialogue qui compare ou pose une valeur non déclarée est relevé au démarrage.

Cas de test : Les usages de drapeaux sont confrontes aux declarations.
Categorie : Unitaire · Quetes
Criticite : Majeur
Etapes :
1. Lire un dialogue qui pose quete.essai = acceptee, compare a accepte (faute) et pose quete.essai sans valeur.
2. Le confronter a la quete d'essai.
3. Relever ce qu'il pose et ce qu'il lit.
Resultat attendu : Deux erreurs, la valeur fautive et la pose sans valeur, nommant le dialogue ; les drapeaux poses comprennent la valeur, le fait de chaque etape et le drapeau declare ; le drapeau lu est quete.essai.

TEST ( QuestAdvanceTest ,
UneQueteDeTroisEtapesAvanceParLesDrapeaux  )

Les drapeaux font avancer une quête de trois étapes jusqu'à sa clôture, une fois chacune.

Cas de test : Une quete de trois etapes avance par les drapeaux.
Categorie : Unitaire · Quetes
Criticite : Critique
Etapes :
1. Declarer les drapeaux de la quete d'essai.
2. Poser tour a tour acceptee, garde-vu, rendue, en faisant avancer les quetes a chaque fois.
3. Faire avancer une fois de plus.
Resultat attendu : Chaque pose atteint exactement son etape ; la derniere pose essai/recompense et clot la quete en reussite, trois etapes au journal ; un nouvel appel ne rend rien.

TEST ( QuestFlagsTest ,
UnDrapeauAValeursEstType  )

Un drapeau déclaré à valeurs refuse une valeur hors de sa liste et rend son initiale.

Cas de test : Un drapeau a valeurs est type.
Categorie : Unitaire · Quetes
Criticite : Critique
Etapes :
1. Declarer quete.pommes a quatre valeurs, initiale inconnue.
2. Lire, poser acceptee, puis une valeur absente, puis le poser sans valeur.
3. L'effacer.
Resultat attendu : L'initiale se lit avant toute pose ; acceptee est acceptee, la valeur absente et la pose sans valeur sont refusees sans rien changer ; l'effacement ramene l'initiale ; chaque changement fait avancer la revision, un refus non.

TEST ( QuestFlagsTest ,
UneConditionSurDrapeauSeLitEtSEvalue  )

Les trois formes d'une condition se lisent et s'évaluent, la valeur initiale comprise.

Cas de test : Une condition sur drapeau se lit et s'evalue.
Categorie : Unitaire · Quetes
Criticite : Critique
Etapes :
1. Lire isSet, equals (une valeur, une liste) et notEquals.
2. Les evaluer sur un drapeau declare a son initiale, puis a condamne.
3. Lire des formes fautives.
Resultat attendu : Chaque forme donne son test ; equals: inconnue tient a l'initiale ; la liste tient pour chacune de ses valeurs ; deux formes a la fois, une liste vide ou un flag absent sont refusees avec un message.

TEST ( QuestLoadTest ,
LeCatalogueDesQuetesRefuseLesDoublons  )

Le catalogue refuse un fichier mal nommé et un drapeau déclaré par deux quêtes.

Cas de test : Le catalogue des quetes refuse les doublons.
Categorie : Unitaire · Quetes
Criticite : Majeur
Etapes :
1. Ecrire trois quetes dans un dossier temporaire : une valide, une dont le nom de fichier differe de l'identifiant, une qui redeclare le drapeau de la premiere.
2. Charger le dossier, puis un dossier absent.
Resultat attendu : Seule la valide est gardee, deux erreurs nomment les fichiers refuses ; le dossier absent donne un catalogue vide sans erreur.
