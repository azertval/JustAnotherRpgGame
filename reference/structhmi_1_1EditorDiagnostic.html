Detailed Description

Un avertissement prêt à afficher, en anglais.

Le Core rend des codes (EX-NFR-011) ; ce module les dit, une fois, pour que le panneau et les tests lisent la même chose. L'éditeur n'a pas de traduction (LOT-EDITOR-01) : une famille d'entité et une propriété s'y nomment par leur identifiant du format (npc, dialogue).
