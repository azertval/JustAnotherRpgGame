 TEST (AnimationCatalogTest, DescriptorFileNameRemplaceLExtension)
 Le nom du descripteur se déduit de celui de l'image en remplaçant l'extension, chemin de sous-dossier conservé : perdre le préfixe ferait chercher le descripteur au mauvais endroit, un piège déjà rencontré sur les clés du cache de textures.
 TEST (AnimationCatalogTest, CoherenceAvecLePngValideeSurSpritesheetAUnRang)

 TEST (AnimationCatalogTest, TailleDImageIncoherenteAvecLePngEstRefusee)
 Une hauteur de PNG différente de la hauteur d'image (plusieurs rangs, non supportés) ou une largeur qui n'est pas un multiple de la largeur d'image sont refusées, avec un message : ce sont les deux façons de se tromper en découpant une planche.
 TEST (AnimationCatalogTest, IndiceDImageHorsBornesDeLaSpritesheetReelleEstRefuse)
 Un indice d'image au-delà de ce que contient réellement la spritesheet est refusé, même quand la largeur est un multiple valide : la validation confronte les clips au fichier, pas seulement le fichier à lui-même.
 TEST (AnimationCatalogTest, FrameRegionPremiereEtDerniereImageSpritesheetAUnRang)
 La région d'une image se déduit de son indice par simple décalage horizontal, l'ordonnée ne variant jamais : c'est la convention de planche à un seul rang, qui rend le découpage prévisible pour l'artiste.
