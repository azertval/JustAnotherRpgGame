Detailed Description

Association action d'éditeur -> touche, avec persistance JSON (EX-CTRL-012).

Échange sur conflit ; persistance dans la section "editeur" de keybindings.json, fusionnée plutôt qu'écrasée à chaque sauvegarde : les autres sections du fichier sont préservées.
