MemeContexteProduitLaMemeAide  )

La restauration apres un message transitoire redonne la meme aide, pour le meme outil.

editorStatusLines est PURE : restaurer la barre d'etat consiste donc simplement a la rappeler avec le meme contexte, sans avoir a memoriser ce qui y etait affiche. Cas de test : La decision est deterministe : meme contexte, meme resultat.
Categorie : Unitaire · Barre d'etat de l'editeur
Criticite : Majeur
Etapes :
1. Calculer deux fois les lignes pour le meme contexte.
2. Comparer.
Resultat attendu : Les deux resultats sont identiques.
