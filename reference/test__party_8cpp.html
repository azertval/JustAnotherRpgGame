LeMeneurEstLePremierDeLOrdreDeMarche  )

Le meneur est le premier de l'ordre de marche (EX-EXP-014).

Cas de test : Choisir un meneur le met en tete sans deranger les autres ; passer la main fait le tour du groupe.
Categorie : Unitaire · Groupe
Criticite : Critique
Etapes :
1. Un groupe de quatre, Brawler en tete ; faire du Priest le meneur.

  1. Passer la main quatre fois.
  2. Echanger les rangs 1 et 3.
    Resultat attendu : Priest, Brawler, Mage, Scoundrel ; chaque passage met le suivant en tete et le meneur en queue, et le quatrieme revient au Priest ; l'echange croise deux suiveurs.

TEST ( PartyTest ,
LesQuatreFichesPreTireesFormentLeGroupeDeDepart  )

Les quatre fiches pre-tirees se proposent, et forment le groupe de depart (EX-EXP-013).

Cas de test : Le dossier des personnages propose les quatre fiches pre-tirees ; une partie neuve les prend toutes, le Brawler en tete.
Categorie : Unitaire · Groupe
Criticite : Majeur
Etapes :
1. Lire Rpg/characters/ sans construire les fiches.

  1. Former le groupe de depart.
    Resultat attendu : Quatre candidats sans erreur, chacun avec son nom, sa classe et son fichier ; sans ordre impose, le groupe les prend dans l'ordre des identifiants ; avec l'ordre du groupe preforme (Brawler, Priest, Scoundrel, Mage), dans celui-la, un identifiant inconnu saute.

QuatreAuPlusJamaisVide  )

Quatre au plus, sans doublon, jamais vide (EX-EXP-013).

Cas de test : Le groupe prend quatre personnages au plus, chacun une fois, et garde toujours son dernier membre.
Categorie : Unitaire · Groupe
Criticite : Critique
Etapes :
1. Ajouter les quatre fiches, puis une cinquieme, puis une deja presente.

  1. Retirer trois membres, puis le dernier.
    Resultat attendu : Quatre membres ; la cinquieme refusee (Full), le doublon aussi (AlreadyMember) ; le dernier membre ne se retire pas (LastMember).
