Detailed Description

Le catalogue chargé, et ce qui n'a pas pu l'être.

Les deux ensemble, jamais l'un ou l'autre : un catalogue dont une entrée sur quatre-vingt- quatorze est illisible reste utilisable, et le refuser en bloc rendrait le jeu injouable pour une virgule. Chaque échec nomme son fichier (EX-CNT-010).
