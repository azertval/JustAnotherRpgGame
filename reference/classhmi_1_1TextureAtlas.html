Detailed Description

Texture d'atlas procédurale et table de régions de tuiles (EX-REN-041/EX-REN-042).

L'atlas est une grille de tuiles 16×16 générée en mémoire (hmi::buildProceduralAtlasImage) : une couleur distincte par type de tuile, et une case à zones transparentes pour valider le rendu alpha. Aucun fichier n'est lu, donc aucun échec de chargement possible (EX-NFR-040). Le canevas de l'éditeur s'en sert pour distinguer les types de terrain à l'œil.
