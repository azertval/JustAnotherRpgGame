L'état d'une carte (LOT-EDITOR-09) vit dans l'annexe : écrit, relu, et absent tant que l'auteur n'a rien dit.

Cas de test : L'annexe garde où en est la carte.
Categorie : Unitaire · Le monde
Criticite : Majeur
Etapes :
1. Écrire une annexe sans état, puis avec « finished ».
2. Relire une annexe dont l'état est un mot inconnu.
Resultat attendu : Sans état, l'annexe est vide et son texte ne porte pas la clé ; avec, elle se relit telle quelle ; un mot inconnu vaut « rien dit ».

Une clé inconnue est gardée et réécrite ; une note mal formée est ignorée, un texte illisible rend une annexe vide, chacun avec un avertissement ; un fichier absent, rien.

Cas de test : L'annexe tolère et garde ce qu'elle ne connaît pas.
Categorie : Unitaire · Notes d'auteur
Criticite : Majeur
Etapes :
1. Lire une annexe avec une clé lockedRegions et une note sans texte.
2. Lire un texte qui n'est pas du JSON.
3. Lire un fichier absent.
Resultat attendu : La clé revient à l'écriture ; une note sur deux, un avertissement ; annexe vide et avertissement ; annexe vide sans avertissement.

Une note par case, retirée par un texte vide ; l'écriture est canonique et relue à l'identique ; une annexe vide retire son fichier.

Cas de test : Les notes s'écrivent, se relisent et se retirent.
Categorie : Unitaire · Notes d'auteur
Criticite : Critique
Etapes :
1. Écrire deux notes, en réécrire une, écrire l'annexe.
2. La relire.
3. Effacer les deux notes, réécrire.
Resultat attendu : Notes triées ligne par ligne, texte JSON canonique ; relue égale ; vide, le fichier part.
