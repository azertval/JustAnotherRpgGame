0.3.0 Classes et espèces, pour de vrai

La vraie complexité : toutes les espèces, les classes complètes et leurs sous-classes, les sorts.

planifiée en détail

Avancement — 0 %

Ce que la version rend jouable

  • Toutes les espèces du Player's Guide et du Manuel des Joueurs, avec leurs assets.
  • Les classes complètes : progression par niveau, sous-classes, sorts.
  • La création de personnage complète.

Critères de sortie

  • Tout personnage que les livres permettent de créer se crée dans le jeu.
  • Chaque classe se joue du niveau 1 au niveau maximal retenu, capacités en main.

La vraie complexité : 12 espèces de Tanares et 9 races du Manuel, 12 + 4 classes, 69 sous-classes, les sorts. L'inventaire, page par page, est dans le référentiel.

Les quatre classes de base de la 0.0.2 restent : ce sont les classes simplifiées du Player's Guide, faites pour qui ne veut pas de la complexité. Le livre interdit le multiclassage vers ou depuis elles.

Ordre conseillé : socle d'espèces → socle de classe → martiaux → sorts → lanceurs → espèces de Tanares → sous-classes de Tanares → Dragonblade et Redeemer → Cirrus → Elementalist → Madwalker. Le Madwalker dépend du plan pénombral (0.17.0) pour ses formes : il se livre ici sans elles, ou attend — à trancher.
