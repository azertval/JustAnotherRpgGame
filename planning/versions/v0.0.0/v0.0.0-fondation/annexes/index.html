Annexes de la version 0.0.0

Ce qu'un lot a laissé à côté de sa fiche : un atelier (scripts, prompts, ancres), des captures, des maquettes de référence, des retouches. Un dossier par lot, sous le nom du lot.

DossierLotCe qu'il contient
LOT-09-colisee-premiere-carte/LOT-09atelier/carte_colisee.py : le script qui écrivait la carte du Colisée, avant que l'éditeur ne sache le faire.
LOT-87-charte-v2/LOT-87Le cahier des assets (engendré de assets-brief.json, contrôlé en CI), les dix maquettes de référence (references/), les captures 720p / 1080p des écrans (captures/), les planches reçues (images-produites/).
LOT-91-atelier-pnj/LOT-91Le PoC et l'atelier des PNJ : ancres, prompts, scripts, cinq PNJ.
LOT-92-atelier-textures/LOT-92L'atelier des textures : maquette, prompts, dispositions.
LOT-93-atelier-monstres/LOT-93L'atelier des monstres : lion, loup, soldat Ironhand.
LOT-96-quartiers-capitale/LOT-96atelier/carte_quartiers.py : le script des cartes de quartier.
LOT-EDITOR-06-fin-des-scripts/LOT-EDITOR-06retouches/ : les trois fichiers de gestes rejoués par LevelEditor --apply.
