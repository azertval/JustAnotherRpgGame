# Manuel utilisateur

Ce manuel s'adresse aux **utilisateurs** (non-développeurs) : comment récupérer et lancer le
jeu, y jouer, et créer/partager des cartes dans l'éditeur.

## Pages

- [Télécharger et lancer le jeu](telecharger-et-lancer.md) — récupérer la dernière version et la lancer.
- [Jouer](jouer.md) — menus, la démo « Des pommes pour l'arène », déplacement, dialogues, combat sur la carte, options.
- [Utiliser l'éditeur de cartes](utiliser-l-editeur.md) — la fenêtre, les outils, les pièces, les entités, le contrôle d'une carte.
- [Créer et partager une carte (sans ligne de commande)](partager-un-niveau.md) — créer une carte dans l'éditeur et la partager avec l'équipe
  via Git, sans ligne de commande.
