# Spécifications

Les spécifications décrivent *quoi* faire et *pourquoi*, indépendamment de
l'implémentation. Elles servent de référence pour découper les [lots de
travail](../../Planning/versions/v0.0.0/v0.0.0-fondation/README.md) et sont tracées par des identifiants d'exigences `EX-…`.

> Un renvoi `LOT-NN` désigne un lot **de ce programme** — il doit exister, livré ou inscrit à la
> [feuille de route](../../Planning/vision/archives/feuille-de-route-jeu.md) ; `scripts/lint_lots.py` le vérifie en CI.
