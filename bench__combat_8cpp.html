Detailed Description

Mesures du combat tactique : déplacement (LOT-19), ligne de vue (LOT-22), IA (LOT-23).

Les scènes sont fixes et déterministes : deux nuits sur le même code mesurent la même chose, et seul le code change la courbe. Chaque mesure construit sa scène hors de la boucle chronométrée.
