TEST ( InventoryScreenTest ,
EmplacementNaturel  )

Chaque objet d'équipement va à son emplacement naturel ; le matériel ne s'équipe pas.

Cas de test : Un objet s'équipe à son emplacement naturel, ou pas du tout.
Categorie : Unitaire · Inventaire
Criticite : Majeur
Etapes :
1. Demander l'emplacement naturel d'un arc, d'une épée, d'une armure, d'un bouclier, d'une torche.

  1. Tenter d'équiper la torche.
    Resultat attendu : Distance, main directrice, torse, main secondaire ; aucun pour la torche, qui reste dans le sac.

Équiper depuis le sac échange avec ce que l'emplacement portait, sans rien perdre.

Cas de test : Équiper depuis l'inventaire rend l'objet remplacé au sac.
Categorie : Unitaire · Inventaire
Criticite : Critique
Etapes :
1. Porter une dague en main directrice, avoir une épée longue dans le sac.

  1. Équiper l'épée depuis le sac.
    Resultat attendu : L'épée est en main directrice, la dague est dans le sac, l'épée n'y est plus.
