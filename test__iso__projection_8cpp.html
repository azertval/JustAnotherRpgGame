Detailed Description

Tests de la projection isométrique du Colisée : positions connues, orientation des axes, allers-retours case ↔ monde, et conformité aux formules de la scène QML qu'elle remplace.

Les valeurs attendues sont calculées à la main dans les commentaires, pas par la fonction testée : une erreur de signe ou d'échelle ici casserait en silence tout le rendu de l'arène.

TEST ( IsoProjectionTest ,
AllerRetourCaseMondeCase  )

Aller-retour case → monde → case, sur toute une grille et près des sommets.

Cas de test : Chaque case d'une grille 12 × 9, projetée à son centre puis relue, redonne la même case ; de même pour quatre points pris juste à l'intérieur de ses sommets.
Categorie : Unitaire · Combat
Criticite : Bloquant
Etapes :
1. Pour chaque case : centre → worldToTile.
2. Pour chaque case : les points de grille (c + 0,02 ; r + 0,02), (c + 0,98 ; r + 0,02), (c + 0,02 ; r + 0,98), (c + 0,98 ; r + 0,98) → monde → worldToTile.
Resultat attendu : Toujours la case de départ.

Aller-retour continu grille → monde → grille.

TEST ( IsoProjectionTest ,
ConformeALaSceneQml  )

Conformité à la scène QML du LOT-50 : même dessin, à une homothétie et une translation près.

Cas de test : Pour plusieurs tailles d'élément et de grille, la position QML de chaque brique ArenaTile vaut décalage + échelle × position monde, où l'échelle est le rapport des largeurs de losange et le décalage celui qui centre la scène.
Categorie : Unitaire · Combat
Criticite : Bloquant
Etapes :
1. Transcrire littéralement les formules de ArenaScene.ui.qml (lignes 36-61).
2. Pour des éléments 1280 × 720, 800 × 900, 640 × 360 et des grilles 16 × 12, 9 × 14, 1 × 1 : comparer la position de chaque case.
Resultat attendu : Égalité à 1e-2 pixel près, pour chaque case.

    3. Lire les sommets exacts de (2, 2).
    4. Lire le centre projeté de (−1, 0), (5, 2), (2, 5) et un point au-dessus de la scène.
    Resultat attendu : Coins : (1, 2), (2, 1), (2, 3), (3, 2) ; sommet haut → (2, 2), sommet droit → (3, 2), sommet gauche → (2, 3), sommet bas → (3, 3) ; hors grille : rien.
