Detailed Description

Ce que le canevas iso montre (LOT-EDITOR-02) : la même liste de primitives que le jeu sur la carte d'essai, et l'effet des réglages de couche sur les bandes de la scène.

TEST ( CanvasSceneTest ,
GriserEtVerrouillerSontDesReglagesDEditeur  )

Griser et verrouiller sont des réglages de l'éditeur, oubliés à l'ouverture d'une carte.

Cas de test : Griser et verrouiller une couche, puis tout oublier.
Categorie : Unitaire · Editeur · Couches
Criticite : Majeur
Etapes :
1. Verrouiller la collision, griser une couche visuelle.

  1. Remettre les reglages a zero.
    Resultat attendu : Les reglages se lisent sur chaque couche ; l'opacite effective d'une couche grisee est reduite ; apres remise a zero, plus rien n'est grise ni verrouille.

LaCarteDEssaiSeComposeCommeDansLeJeu  )

La carte d'essai ouverte dans l'éditeur produit la même liste de primitives que dans le jeu.

Cas de test : Le canevas iso compose une carte comme le jeu.
Categorie : Unitaire · Editeur · Canevas
Criticite : Bloquant
Etapes :
1. Ouvrir la carte d'essai comme brouillon d'editeur et prendre l'instantane du canevas.

  1. Entrer dans la carte d'essai avec le moteur du jeu (hmi::WorldPlay) et prendre son instantane.
  2. Composer les deux avec les memes textures.
    Resultat attendu : Les instantanes sont egaux, heros mis a part ; les listes de primitives sont egales, dans le meme ordre, a la figurine du heros pres.

TEST ( CanvasSceneTest ,
LesReglagesDeCoucheAgissentSurLeurBande  )

Les réglages d'une couche agissent sur sa bande de la scène iso.

Cas de test : Masquer, griser, voir a travers : chaque reglage agit sur sa bande.
Categorie : Unitaire · Editeur · Canevas
Criticite : Majeur
Etapes :
1. Une carte a couche de sol et couche de decor, reglages par defaut.

  1. Masquer le decor, griser le sol, activer les reliefs en transparence.
  2. Rendre la collision active.
    Resultat attendu : Par defaut tout est plein et la collision cachee ; masque, le relief tombe a 0 ; grise, le sol tombe a DIMMED_LAYER_OPACITY ; en transparence, le relief a SEE_THROUGH_RELIEF_OPACITY ; la collision ne se montre que quand on la peint.
