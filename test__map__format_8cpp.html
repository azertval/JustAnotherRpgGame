Acceptation du lot, sur chaque carte livrée : sa version v3, rangée dans JADG_V3_MAPS_DIR (tirée de l'historique git), se joue comme sa v4 migrée.

Le seul test de ce fichier à lire les cartes livrées, et c'est son objet ; il admet qu'il n'y en ait aucune (LOT-123), et ne saute que les cartes sans version v3. Cas de test : Chaque carte migrée se joue à l'identique.
Categorie : Unitaire · Format v4
Criticite : Critique
Etapes :
1. Extraire les v3 : git show 376c541da:Source/Elements/Levels/… (le dernier commit de main avant ce lot).

  1. JADG_V3_MAPS_DIR=<dossier> puis lancer ce test.
    Resultat attendu : Même instantané de scène, même grille tactique, pour chaque carte. Ignoré sans la variable.
