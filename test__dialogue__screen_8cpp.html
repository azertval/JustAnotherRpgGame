TEST ( DialogueScreenTest ,
LeJetSeRestitueSurLaRepliqueQuiSuit  )

Le jet joué par une réponse se restitue sur la réplique qui en découle, et seulement sur celle-là.

Cas de test : Le jet se restitue sur la replique qui suit, puis s'efface.
Categorie : Unitaire · Interface
Criticite : Majeur
Etapes :
1. Negocier (bonus +30 contre 10).
2. Lire les valeurs.
3. Continuer jusqu'a la fin.
Resultat attendu : Apres le jet : attitude amicale, restitution « competence : total contre 10 – reussite », une reponse « continuer ». A la fin : termine, restitution effacee, une seule reponse « quitter ».

TEST ( DialogueScreenTest ,
UneRepliqueAnnonceLeJetDeSaReponse  )

Une réplique en attente s'affiche traduite, et une réponse qui mène à un jet l'annonce.

Cas de test : L'ecran de dialogue annonce le jet avant le choix.
Categorie : Unitaire · Interface
Criticite : Majeur
Etapes :
1. Ouvrir un dialogue de garde hostile.
2. Lire les valeurs de l'ecran.
Resultat attendu : Nom, attitude hostile et replique par leur cle ; deux reponses dans l'ordre ; la premiere porte « [competence] » avec la cle de lexique a tiret bas ; aucune restitution de jet ; l'ecran n'est pas termine.
