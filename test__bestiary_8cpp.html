Detailed Description

Tests du bestiaire de base (LOT-33) : les 94 profils chargent, et dix sont rejoues contre des valeurs RECOPIEES A LA MAIN d'Animaux.pdf.

Le second point est l'acceptation du lot, et il n'est pas negociable dans sa forme : les valeurs ci-dessous ont ete lues sur le PDF, pas copiees depuis le JSON produit. Un test qui comparerait la sortie de la generation a elle-meme passerait quelle que soit la faute d'extraction – c'est exactement la panne qu'il doit exclure.

Toute creature porte les six caracteristiques et une vitesse de marche.

Cas de test : Aucun profil du bestiaire n'a de caracteristique ni de vitesse manquante.
Categorie : Unitaire · Bestiaire
Criticite : Critique
Etapes :
1. Pour chaque creature, verifier que les six caracteristiques sont dans [1, 30].

  1. Verifier que la vitesse de marche est renseignee, meme nulle.
    Resultat attendu : Les 94 profils passent ; une extraction incomplete echoue ici.

Dix profils sont rejoues contre les valeurs du PDF, recopiees a la main.

Cas de test : Dix blocs de statistiques du bestiaire concordent avec le livre.
Categorie : Unitaire · Bestiaire
Criticite : Critique
Etapes :
1. Pour douze creatures, comparer classe d'armure, points de vie, vitesse de marche, facteur de puissance et degats de l'attaque principale aux valeurs lues sur Animaux.pdf.
Resultat attendu : Les cinq valeurs coincident pour chacune ; une extraction decalee d'une ligne fait echouer ce test.
